# Accessibility statement

SkillTrait aims to support keyboard navigation, screen readers, visible focus,
text zoom, and reduced-motion preferences in its primary workflows.

This repository is currently a non-production validation project and has not
received a formal WCAG conformance audit. Accessibility defects should be
reported through GitHub Issues with the affected page, browser, assistive
technology, and reproduction steps. Security-sensitive reports should follow
the private process in `SECURITY.md`.

Before any future release, maintainers should test the complete sign-in,
navigation, upload, skills, team, award-generation, and sharing workflows using
keyboard-only navigation and at least one current screen reader.
